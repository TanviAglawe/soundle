# Soundle

Soundle is a music artist guessing game developed using Python and Flask.

## Features

- Mystery artist guessing
- Creative hints
- Artist autocomplete
- Five guesses
- Guess comparison using genre, country, debut year, artist type and popularity
- Score system
- Result page

## Technology

- Python
- Flask
- HTML
- CSS
- JavaScript
